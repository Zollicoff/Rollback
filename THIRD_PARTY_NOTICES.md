# Runtime and tool acknowledgments

The game is compiled with [GBDK-2020 4.5.0](https://github.com/gbdk-2020/gbdk-2020/releases/tag/4.5.0), including the SDCC compiler and runtime. The GBDK runtime library is distributed with GPLv2 and a linking exception; its supplied text is preserved in `LICENSES/GBDK_LIBRARY.txt`. Upstream source is available from the linked GBDK repository and its [SDCC toolchain repository](https://github.com/gbdk-2020/gbdk-2020-sdcc).

Development and verification use [PyBoy](https://github.com/Baekalfen/PyBoy), Pillow, NumPy, and SDL2. These tools are installed separately and are not bundled in the game release. Their licenses remain with their respective packages.

The Rollback font, scenery, portrait, vehicle sprites, and sound patterns in this prototype were authored for this project. No third-party commercial game artwork, music, or dialogue was imported.
